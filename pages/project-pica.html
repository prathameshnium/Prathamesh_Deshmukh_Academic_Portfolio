PICA: Python-based Instrument Control and Automation

PICA is a modular open-source software suite designed to automate advanced transport measurements. It supports resistance measurements covering 24 orders of magnitude (10-8 to 1016 Ω) and orchestrates Keithley, Keysight, Lakeshore, Cryo-con and Novocontrol instruments over GPIB/VISA and SCPI for cryogenic transport, resistivity, I-V, dielectric, pyroelectric and memristor measurements, using a multiprocessing, fault-tolerant architecture. Validated in the lab with a Quantum Design PPMS (5-380 K, up to 14 T).

Motivation & Key Features

Motivation

Researchers often face a binary choice: purchase expensive proprietary software or develop custom measurement scripts from scratch. PICA builds upon powerful libraries like PyVISA and PyMeasure to offer a turnkey application. It provides a ready-to-run graphical interface that abstracts the underlying control logic, allowing experimentalists to focus on data acquisition without extensive software development overhead.

Key Features

  • Accessibility: A GUI launcher lets researchers without coding experience configure and run measurement protocols from pre-packaged modules.
  • Operational Validation: Validated via cryogenic transport measurements with a custom probe in a PPMS (5-380 K, up to 14 T) at UGC-DAE CSR, Mumbai.
  • Fault Tolerance: Each measurement program runs in its own process, so a hardware timeout or driver crash never freezes the launcher.
  • CLI Templates: About fifteen measurements also ship an Instrument_Control script for headless automation.
  • Operational Transparency: Real-time, time-stamped logs of every operation aid debugging and reproducibility.
  • Extensibility: Every module is one self-contained file; add an instrument by copying the closest module and changing its SCPI commands.

Design & Implementation

Hardware Abstraction

Utilizes PyVISA to abstract low-level communication (GPIB, USB, Ethernet). Implements strict initialization routines: connection verification via *IDN?, instrument resets (*RST/*CLS), and safe shutdown that switches off sources and heaters on finish, stop, error or window close.

Process Isolation

Decouples the UI from instrumentation logic using Python's multiprocessing. This prevents UI freezes during long acquisitions and ensures hardware timeouts don't crash the main dashboard.

Data Integrity

A "write on acquisition" strategy ensures data is saved to CSV via pandas immediately after every point, preventing loss during power failures or system hangs.

PICA includes a testing suite using pytest and unittest.mock to simulate VISA resources, allowing logic verification without physical hardware. The suite has 3,500+ tests, all run against mocked instruments.

Utilities & Tools

  • VISA Instrument Scanner: queries the GPIB/USB/Ethernet bus (*IDN?) to map connected instrument addresses.
  • PICA Plotter Utility: multi-file plotting for comparison during or after measurements.
  • SCPI Console: interactive terminal for sending raw SCPI commands to any VISA instrument.
  • Diagnostic Tools: read-only checks of the Python environment, drivers, interfaces, the Cryo-con 34 and the Alpha-AN.
  • PPMS Helpers: plotter, sequence visualizer and time estimator for Quantum Design PPMS workflows.
  • Calculators & Helpers: List Maker, Quick Calc, unit converter, MD-ratio calculator, PID simulator, Time Utility and Memristor Analysis.

Understanding "Delta Mode"

"Delta Mode" refers specifically to a technique used by Keithley Models 6220 and 6221 in conjunction with the Model 2182/2182A Nanovoltmeter for ultra-low resistance measurements. It cancels thermal EMFs via an AC method. In PICA, "Ultra Low Resistance Measurements" is the general term used, while "Delta Mode" appears in specific Keithley-related modules.

Getting Started

Option 1: Install from PyPI (Recommended)

pip install pica-suite

Option 2: Install from Source

git clone https://github.com/prathameshnium/PICA-Python-Instrument-Control-and-Automation.git
cd PICA-Python-Instrument-Control-and-Automation

2. Create Virtual Environment & Install

# Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate

# Install the package and its dependencies
pip install .

To update PICA to the latest version, run the following command in the project directory:

pip install --upgrade .

If you are already in your virtual environment and want to force Python to reinstall the package (overwriting the old one), run this in your root project folder:

pip install --force-reinstall .

Note: Ensure you have the NI-VISA drivers installed on your host machine to allow PyVISA to communicate with the hardware.

Running the Software

1. Graphical Launcher (Recommended)

The central dashboard for accessing all modules, the plotter, and the scanner.

pica-gui

You can also run any of the individual GUI measurement modules independently. This is useful for quickly accessing a specific measurement without opening the main launcher. To do this, simply run the Python script for the desired module.

For example:

python -m pica.keithley.k6517b.High_Resistance.IV_K6517B_GUI

2. Launcher v2 (in testing)

Opens on a Quick Select screen (category, module and protocol, each explained in plain language) and keeps every module in an Advanced Options window (Ctrl+Shift+A). Ctrl+F searches every program by name, instrument or input field. The classic pica-gui launcher remains the canonical one.

python -m pica.main_v2

3. Command Line Interface (CLI)

For headless operation, without the GUI.

pica-cli

Important

Template Scripts: The instrument control modules (CLI's) provided are designed as template scripts. Users are expected to modify these scripts programmatically to adapt them to their specific experimental requirements and custom workflows. They are also excellent for developing custom measurement protocols, sequences, and for learning instrument automation. These scripts are typically named with an 'Instrument_Control' suffix to denote their programmatic nature. This approach ensures maximum flexibility and customization for advanced research applications.

Note

Legacy CLI Notice: The PICA CLI (pica-cli) is retained to support legacy headless workflows. While fully functional for specific protocols, this interface is less frequently maintained and may not support recent features available in the GUI.

We strongly recommend new users utilize the PICA GUI for the most complete and supported experience.

System Requirements & Compatibility

  • Windows 10 / 11 (x86_64): fully supported, and used daily in the lab with real instruments.
  • Linux: installation, tests and GUIs verified; measurements against real instruments not yet verified.
  • macOS: not tested.

Note

The 32-bit Novocontrol Alpha-AN frequency scan and the 32-bit GPIB scanner call the Windows gpib-32.dll directly, so they run on Windows only.

A VISA Backend is Required

PyVISA is a wrapper, not a driver. You must install a backend:

  • NI-VISA: The industry standard from National Instruments.
  • PyVISA-py: A pure Python backend (installed as a fallback).

Installing on Linux

Warning

Talking to real instruments from Linux has not been verified yet. Installation, the full test suite and the GUI windows are checked on Ubuntu in CI; lab use so far has been on Windows.

  1. System packages: sudo apt install python3-venv python3-tk fonts-noto-color-emoji (Debian/Ubuntu).
  2. Install PICA: create a venv, activate it with source ~/pica-venv/bin/activate, then pip install pica-suite.
  3. VISA backend: the pure-Python pyvisa-py is installed for you. USB-TMC needs pyusb and a udev rule; GPIB cards need the linux-gpib driver and pip install "pica-suite[gpib]".
  4. Run: pica-gui. For overnight runs, block sleep with systemd-inhibit.

Full details are in the Linux install guide.

Running Tests

The suite has 3,500+ tests, all run against mocked VISA instruments, so no hardware is needed. To run it locally, first install the development dependencies:

pip install -r requirements-dev.txt

Then, you can run the tests:

python -B -m pytest -p no:cacheprovider

How to Check Coverage Locally

To see the coverage percentage on your local machine, run this command instead:

python -B -m pytest --cov=pica --cov-report=term-missing -p no:cacheprovider
